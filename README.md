# Face-Recognition-Attendance
The Face Recognition Attendance System is a real-time attendance tracking application developed using Python, OpenCV, and the face_recognition library. 
It automates the process of recording attendance by recognizing faces through a webcam and logging the data into a CSV file with accurate timestamps. 
The system detects and identifies individuals in real-time, providing visual feedback by drawing labeled bounding boxes around recognized faces. 
To ensure accuracy, it prevents duplicate entries and optimizes performance using face encodings for fast and reliable recognition. 
This project effectively demonstrates the use of computer vision and automation technologies to streamline attendance management.
